# Bank Account Management System

This is my Java OOP assignment. I created a simple bank account program using classes and objects.

The program allows users to:
- Create two bank accounts.
- Deposit money.
- Withdraw money.
- Check the account balance.
- View account details.

### Java Concepts Used
- Class and Object
- Constructor
- Methods
- Encapsulation

### How to Run
1. Compile the file using `javac Main.java`.
2. Run the program using `java Main`.
